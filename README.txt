ARACHNAID AXE — PaperMC 1.21.11 Plugin (1-Craft Unique + Custom Texture Support)
================================================================================

HOW TO BUILD THE .JAR (Free GitHub Actions — No local setup):
1. Extract this ZIP file into a normal folder.
2. Create a free repository on github.com.
3. Upload ALL extracted files/folders (.github, src, build.gradle.kts, settings.gradle.kts, README.txt).
4. Open the "Actions" tab -> wait ~1 minute for "Build ArachnaidAxe Plugin" to turn green.
5. Download "ArachnaidAxe-Plugin-JAR" from Artifacts, unzip it, and place ArachnaidAxe-1.0.0.jar in your Paper 1.21.11 plugins/ folder.

TEXTURE PACK:
Drop ArachnaidAxe-TexturePack-1.21.11.zip directly into .minecraft/resourcepacks/ (do NOT unzip it),
or host it on your server via server.properties (resource-pack=...).
